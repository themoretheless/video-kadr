# Раунд 11: бэклог на 100 идей (по мотивам реальных редакторов)

Честно: это бэклог-брейншторм, а не план и не обязательство. Идеи сгенерированы
параллельным фан-аутом по 10 категориям (по 10 идей), привязаны к нашей
архитектуре (Rust/Axum + ffmpeg/ffprobe/yt-dlp, Vue 3 без UI-библиотек) и к тому,
как фичи сделаны в Premiere / DaVinci Resolve / CapCut / Final Cut / Descript /
Shotcut / Kdenlive / HandBrake / Veed / Kapwing.

Оценка трудозатрат: **S** = часы, **M** = день-два, **L** = неделя+.
Многие идеи опираются на «таймлайн», которого ещё нет, - он сам по себе крупный
кусок (категория 1) и разблокирует половину остального.

---

## 1. Таймлайн и базовый монтаж

1. **Мультитрек-таймлайн** - вертикально сложенные дорожки видео/аудио, рендер по слоям в один результат. Premiere/Resolve. **L**. Фронт хранит массив дорожек с клипами, бэкенд собирает ffmpeg overlay+amix граф из JSON.
2. **Razor-инструмент** - клик по клипу разрезает его на две независимые части в точке курсора. Все редакторы. **S**. Фронт делит клип-объект на два с общим source и смежными in/out.
3. **Ripple delete** - удаление клипа со сдвигом последующих влево без зазора. Premiere/Resolve. **S**. Фронт убирает клип и пересчитывает start-офсеты остальных.
4. **Магнитное прилипание (snapping)** - края клипов и плейхед липнут к соседним границам/маркерам. Final Cut/Resolve. **M**. При drag ищем ближайшую границу в пороге px.
5. **Маркеры на таймлайне** - цветные именованные метки времени для навигации и заметок. Premiere/Resolve. **S**. Список {time,label,color}, клик прыгает плейхедом.
6. **J/L-cuts** - аудио клипа заходит раньше или тянется дольше его видео. Premiere/Resolve. **M**. Раздельные in/out видео/аудио, бэкенд берёт раздельные -ss в графе.
7. **Slip-инструмент** - сдвиг in/out внутри клипа без изменения позиции и длины. Premiere/Resolve. **M**. Двигаем source-in/out на одну дельту, держим start и длительность.
8. **Slide-инструмент** - перемещение клипа с автоподрезкой соседей под зазор. Premiere/Resolve. **M**. Меняем start и зеркально корректируем out левого и in правого соседа.
9. **Группировка клипов** - связывание клипов для перемещения/резки как единого целого. Premiere/Final Cut. **S**. Поле groupId, операции применяются ко всем с тем же id.
10. **Аудиоволна на клипе** - визуализация громкости на дорожке для нарезки по звуку. Audacity/Resolve. **M**. ffmpeg `showwavespic` → PNG, фронт растягивает под длину.

## 2. Аудио

1. **Аудиоволна под плеером** - осциллограмма всей дорожки для навигации по звуку. Premiere. **M**. `showwavespic` → PNG, клик сикает.
2. **Loudnorm (EBU R128)** - двухпроходная нормализация к целевому LUFS. DaVinci/Fairlight. **M**. Первый проход `loudnorm` с `print_format=json`, второй с измеренными значениями.
3. **Авто-ducking под голос** - приглушает музыку, когда говорит спикер. Premiere/Audacity. **L**. `sidechaincompress` с голосом как ключом.
4. **Фоновая музыка** - аудиотрек поверх видео с уровнем и лупом. CapCut. **M**. `amix`/`amerge` + `volume`, `aloop` под длину.
5. **Шумоподавление** - убирает гул/шипение с голоса. Audacity/Descript. **M**. `afftdn` или `arnndn` с моделью, ползунок силы.
6. **Графический эквалайзер** - коррекция тембра пресетами (бас/голос/радио). Audacity/Fairlight. **M**. `firequalizer` или цепочка `equalizer`.
7. **Ключевые кадры громкости** - кривая громкости по точкам вдоль клипа. Premiere/Final Cut. **L**. `volume=volume='expr'` кусочно-линейно от `t`, редактор точек на канвасе.
8. **Извлечь/заменить аудиодорожку** - вытащить звук в файл или подменить дорожку. Premiere. **S**. `-map` + `-vn`/`-an` и `-c copy` для подмены без перекодирования видео.
9. **Моно/стерео и баланс** - свести в моно, дублировать канал, панорама L/R. Audacity/Fairlight. **S**. Фильтр `pan` с ползунком баланса.
10. **Детекция битов** - находит удары и ставит маркеры для нарезки под ритм. CapCut. **L**. onset-анализ, метки на таймлайне.

## 3. Текст, титры и субтитры

1. **Авто-сабы с «вирусными» стилями** - whisper + пресеты (крупный шрифт, активное слово боксом, поп-анимация). CapCut. **M**. Слова с таймкодами → .ass с \k-тегами → subtitles/ass-фильтр.
2. **TTS-дорожка** - набираешь текст, бэкенд синтезирует озвучку на таймлайн. Veed. **M**. Шеллить piper/espeak-ng в wav → amix.
3. **Edit-by-transcript** - удаляешь слова в расшифровке, куски вырезаются из ролика. Descript. **L**. Word-level таймкоды из whisper → trim+concat по оставшимся.
4. **Авто-перевод сабов** - перевод .srt на другой язык с сохранением таймкодов. Kapwing. **M**. Парсим .srt → argos-translate/LLM → пересобираем → subtitles.
5. **Анимированные текстовые пресеты** - заголовки входят/уходят typewriter/slide/fade/pop. Premiere (Essential Graphics). **M**. .ass с \t/\move/\fad по пресету.
6. **Авто-хайлайт ключевых фраз** - важные фразы крупными «word art» врезками. CapCut. **L**. Эвристика по громкости/паузам → drawtext-врезки.
7. **Speaker-label сабы** - разные говорящие получают свой цвет/имя. Descript. **L**. Простая диаризация → маппинг спикер→стиль в .ass.
8. **Прогресс-бар ролика + счётчик** - тонкая полоса и «N из M» для shorts. Veed. **S**. drawbox шириной от t/duration + drawtext-счётчик.
9. **Кликабельный саб-редактор на таймлайне** - двигаешь/режешь блоки реплик мышью. Final Cut. **L**. Vue-дорожка сабов → сериализация в .ass/.srt.
10. **Выноски и подписи-стрелки** - баблы/стрелки, привязанные к точке кадра. Kapwing. **M**. drawtext + drawbox/линии или PNG-оверлей через overlay.

## 4. Цвет и визуальные эффекты

1. **3-Way Color Wheels (Lift/Gamma/Gain)** - раздельная подкраска теней/средних/светов. DaVinci. **M**. Колёса → `curves` per-channel или `colorbalance`.
2. **LUT-браузер с интенсивностью** - .cube пресеты + ползунок силы. Premiere Lumetri. **M**. `lut3d` + `blend` микс с оригиналом.
3. **Live-скопы (vectorscope/waveform)** - реальные скопы по кадру, не CSS-имитация. DaVinci. **M**. Бэкенд `waveform`/`vectorscope`/`signalstats` → PNG.
4. **Авто-баланс белого по пипетке** - клик по серой точке → коррекция баланса. Lightroom/Resolve. **M**. RGB пикселя → гейны → `colorchannelmixer`.
5. **HSL-квалифайер (keyer по цвету)** - правка только выбранного диапазона hue/sat/luma. Resolve/Lumetri. **L**. `colorkey`/`hsvkey` маска + правка на зоне.
6. **Глитч/RGB-split** - смещение каналов и артефакты как стиль. CapCut. **S**. `rgbashift`/`chromashift` + опц. `noise`.
7. **Halftone/posterize/dither** - постеризация и растр под комикс/ретро. CapCut/Photoshop. **S**. `pp`/`curves`-пороги/dither-фильтры.
8. **Duotone/Tritone** - перекраска в 2-3 цветовые зоны. Premiere/Photoshop. **S**. Сгенерированный `lut3d`/`lutrgb` поверх grayscale.
9. **Авто-цвет/авто-уровни** - растяжка контраста по статистике кадра. Premiere/Photoshop Auto. **M**. `signalstats`/гистограмма → `curves`/`eq`.
10. **Selective saturation / vibrance** - поднимает насыщенность приглушённых цветов без пересвета. Lightroom/Lumetri. **M**. Фильтр `vibrance` или `colorchannelmixer`.

## 5. Переходы и анимация

1. **Whip-pan переход** - размытый рывок камеры между клипами. CapCut. **M**. tblend/boxblur с растущим углом + smoothleft/right xfade.
2. **Glitch/RGB-split переход** - цифровой сбой с разделением каналов. Premiere. **M**. rgbashift с анимированным смещением + xfade=fade.
3. **Light leak / flash-to-white** - вспышка засветки на склейке. Final Cut. **S**. xfade=fadewhite + градиентный overlay с пиком alpha.
4. **Speed ramp по ключевым точкам** - разгон/торможение скорости по точкам. DaVinci (Retime). **L**. Кусочный setpts + minterpolate на замедлении.
5. **Match-cut по позиции/масштабу** - плавный переход с подгонкой кадрирования. Premiere (Morph Cut). **M**. zoompan/crop from→to bbox + короткий dissolve.
6. **Анимированный каллаут с траекторией** - подпись по кривой с ease-in/out. CapCut. **M**. drawtext с x/y как выражениями от t + alpha-fade.
7. **Spin/rotate blur переход** - закрутка кадра между клипами. CapCut. **M**. rotate с анимированным углом + tmix/tblend + circleopen/close.
8. **Push/slide с параллаксом** - выезд клипа с разноскоростным фоном. Final Cut. **L**. overlay двух источников с x=expr разной скорости.
9. **Bounce/elastic вылет PiP** - картинка-в-картинке залетает с пружиной. CapCut. **M**. overlay с x/y по exp*sin от t + scale-pop.
10. **Clock-wipe / radial reveal** - круговая зачистка между клипами. Premiere (Clock Wipe). **S**. xfade=radial или luma-маска через geq.

## 6. ИИ/ML-функции (локальные модели)

1. **Speaker-switch авто-кадрирование** - в диалоге режет план по активному спикеру (мультикам). Descript/CapCut. **L**. whisper-диаризация + pyannote → crop/zoom по таймкодам.
2. **Удаление слов-паразитов** - вырезает «эм/ну/like» одним кликом. Descript. **M**. whisper word-timestamps + словарь → список вырезов для concat.
3. **Eye-contact correction** - перенаправляет взгляд в камеру. Descript/NVIDIA Broadcast. **L**. ONNX gaze-redirection покадрово.
4. **Авто-B-roll по тексту** - под фразы подбирает и врезает релевантный клип. Opus Clip/Veed. **L**. whisper → CLIP-эмбеддинг матч с локальной коллекцией → overlay.
5. **Viral-score нарезка** - режет длинное видео на кандидаты-шортсы и ранжирует. Opus Clip. **L**. whisper по сегментам + локальная LLM скорит хук/эмоцию.
6. **Punch-in на акцентах** - лёгкий зум-ин на громких/эмоциональных репликах. CapCut/Premiere Sensei. **M**. RMS-громкость/VAD + whisper → zoompan по пикам.
7. **Studio Sound (дереверб)** - убирает эхо комнаты, «студийный» голос. Adobe Enhance/Descript. **M**. Локальная модель (DeepFilterNet onnx) поверх RNNoise.
8. **Авто-музыка с beat-sync** - подбирает трек и режет видео по битам. CapCut. **M**. aubio/librosa onset → cut-точки → выравнивание в ffmpeg.
9. **Match-color между клипами** - выравнивает баланс/экспозицию разных клипов. DaVinci Neural Engine. **M**. Гистограммный матчинг → curves/eq.
10. **Эмоция/реакция-маркеры** - метки «смех/пауза/громко/аплодисменты». Premiere Sensei. **M**. Аудио-классификатор (YAMNet onnx) → маркеры.

## 7. Проекты и рабочий процесс

1. **Сохранение/загрузка проекта (.vproj)** - исходники+таймлайн+эффекты в один файл. Premiere/Shotcut. **M**. POST /projects сериализует стор, GET восстанавливает.
2. **Автосохранение** - периодически пишет стейт, чтобы не терять работу. Premiere. **S**. Таймер шлёт стейт на PUT /autosave, N снапшотов.
3. **История версий проекта** - именованные ревизии с откатом. DaVinci. **M**. Каждый save → снапшот-файл с timestamp.
4. **Шаблоны проектов** - старт из заготовки (формат соцсети, набор эффектов). CapCut. **S**. Пресет-JSON в templates/, копирование в новый проект.
5. **Очередь рендера** - несколько экспортов последовательно с общим прогрессом. DaVinci/Premiere. **M**. VecDeque задач, воркер берёт по одной.
6. **Прокси-монтаж** - лёгкие прокси для тяжёлых исходников, экспорт на оригинале. Premiere/DaVinci. **L**. При импорте ffmpeg делает proxy-файл, флаг use_proxy.
7. **Дублирование/сравнение вариантов экспорта** - A/B результатов рядом. Final Cut. **S**. POST /outputs/:id/duplicate, сетка сравнения.
8. **Теги, папки и поиск в медиатеке** - организация и фильтр. Premiere (Bins)/DaVinci. **M**. Поля tags/folder в library.json, GET /library?tag=&q=.
9. **Недавние проекты** - стартовый экран с превью последних. DaVinci/CapCut. **S**. recent в localStorage + кадр-постер.
10. **Batch-импорт папки** - добавить все видео из папки разом. Premiere/Shotcut. **M**. POST /library/import-folder сканит и заводит записи.

## 8. Экспорт и шеринг

1. **Профили устройств** - пресеты iPhone/Android/AppleTV/PS5 с совместимыми кодеками. HandBrake. **S**. Словарь `-profile:v`/`-level`/`-pix_fmt`.
2. **Faststart для веба** - moov-атом в начало mp4 для мгновенного старта. HandBrake. **S**. Флаг `-movflags +faststart` + чекбокс.
3. **Очередь экспорта с приоритетами** - несколько заданий последовательно. HandBrake. **M**. VecDeque + один воркер + SSE-стрим статуса.
4. **Сабы: вшить или прицепить** - hardsub (прожечь) или мягкая дорожка mov_text. Veed/HandBrake. **M**. `subtitles=` или `-c:s mov_text`.
5. **Boomerang-луп** - прямой+обратный проход для бесшовного цикла. CapCut/Kapwing. **S**. `[0]reverse[r];[0][r]concat`.
6. **QR на ссылку результата** - открыть файл на телефоне. Veed/Kapwing. **S**. Крейт `qrcode` → PNG рядом с шерингом.
7. **Нормализация громкости при экспорте** - выравнивание до целевого LUFS на выходе. Premiere/Veed. **M**. `loudnorm=I=-14` или `volume`.
8. **Спид-рамп при экспорте** - ускорение/замедление с ресемплингом аудио. Premiere/CapCut. **M**. `setpts=PTS/N` + `atempo`.
9. **Профиль «<25 МБ» для мессенджеров** - уместить в лимит вложения. HandBrake/Discord. **S**. Таргет-сайз с авто-понижением до 720p.
10. **Экспорт только in/out-диапазона** - рендер лишь отмеченного отрезка. Premiere/Veed. **M**. Прокинуть `-ss`/`-to` из выбранных точек.

## 10. Производительность и инфраструктура

1. **GPU/HW авто-детект кодека** - videotoolbox/nvenc/vaapi вместо libx264. ffmpeg. **M**. Один раз `ffmpeg -hwaccels`, кэш в state, выбор в билдере.
2. **Smart-render (stream copy)** - `-c copy` когда пиксели не трогаем. ffmpeg. **M**. Флаг «lossless-возможен» в дескрипторе операции.
3. **Кэш ffprobe** - метаданные по (path, mtime, size). content-addressed. **S**. `HashMap` за `RwLock`, инвалидация по mtime.
4. **Дисковый кэш миниатюр** - кадры-превью раз и в `cache/thumbs/<hash>`. thumbnail cache. **M**. Ключ sha256(path+ts), проверка наличия перед генерацией.
5. **Персистентные задачи** - снапшот задач в `jobs.json`, пережить рестарт. WAL-snapshot. **M**. Сериализация статуса, дебаунс записи, восстановление при boot.
6. **Трейсинг + метрики** - `tracing` span на задачу + `/metrics` (Prometheus). tracing/metrics. **M**. Subscriber + counter/histogram в ключевых точках.
7. **Healthcheck бинарей** - `/healthz` проверяет ffmpeg/ffprobe/yt-dlp и свободное место + Docker HEALTHCHECK. Docker. **S**. Шелл `-version` + statvfs.
8. **Streaming-отдача с Range** - 206 Partial Content для сика в `<video>`. HTTP Range. **M**. Парсинг `Range`, seek, `Content-Range`/`Accept-Ranges`.
9. **Watchdog на зависший ffmpeg** - нет прогресса N сек → kill с понятной ошибкой. watchdog. **S**. `tokio::time::timeout` на инкремент прогресса.
10. **Concat без перекодирования** - concat-demuxer `-f concat -c copy` для совместимых сегментов. ffmpeg. **M**. `list.txt` + один проход, фоллбэк на перекодирование.
