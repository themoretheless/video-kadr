# Топ-10 идей «как в других редакторах», раунд 10

Раунд 9 реализован (полировка UI): светлая/тёмная тема с переключателем в шапке и
сохранением выбора; undo/redo настроек редактирования (стек снимков + горячие клавиши
Cmd/Ctrl+Z, Cmd/Ctrl+Shift+Z, Ctrl+Y, кнопки в панели); именованные пресеты эффектов
(сохраняются в localStorage, переносятся между клипами, без клип-специфичной геометрии
trim/crop/censor). Плюс попутно исправлено сообщение об ошибке, когда бэкенд не запущен:
вместо «/api/import -> HTTP 500» теперь «Сервер недоступен. Запущен ли бэкенд?». Дальше -
следующий конкурентный срез.

1. Проекты: сохранить весь набор настроек клипа как именованный «проект» и переоткрыть
   позже (как пресеты, но с trim/crop/сегментами). Аналог .prproj/.drp (Premiere, DaVinci). [новое]
2. Звуковая дорожка-волна под плеером для точной нарезки по пикам/паузам (любой NLE). [новое]
3. Фоновая музыка с автоприглушением под речь (ducking): amix + sidechaincompress (CapCut). [новое]
4. Авто-субтитры из речи (whisper) и вшивание в видео; нужен libass в сборке ffmpeg (CapCut). [новое]
5. Импорт LUT (.cube) для киношной цветокоррекции через фильтр lut3d (DaVinci, Premiere). [новое]
6. Плёнка-миниатюры (filmstrip) под таймлайном: кадры через ffmpeg по равным отрезкам (Premiere). [новое]
7. Скоростные рампы: переменная скорость по кривой, а не один множитель (CapCut, Premiere). [новое]
8. Переходы между склеенными сегментами (xfade/acrossfade) вместо жёсткой стыковки (iMovie). [новое]
9. Размытый фон под letterbox (как в Shorts/Reels): split + gblur + overlay вместо чёрных полей. [новое]
10. Стоп-кадр/заморозка: вставка замороженного кадра на N секунд (tpad/loop) (Filmora, CapCut). [новое]

Большие списки: round-01..04. round-05..10 - короткие конкурентные срезы под цикл.
Заметка по фидбэку: HTTP 500 на импорте в дев-режиме почти всегда значит, что не поднят
бэкенд (cargo run на :8080) - Vite-прокси отдаёт 500 при ECONNREFUSED. Теперь это видно в UI.
