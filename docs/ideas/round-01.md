# Топ-100 идей, раунд 1

Сгенерировано по состоянию MVP (импорт по URL, trim/crop/scale/mute/speed, экспорт MP4).
В раунде 1 реализуются: 37, 40, 41, 42, 43, 48, 49, 50, 51, 59, 75, 78, 79, 80, 81, 84 (частично), 85, 87, 89, 93.

## Монтаж и эффекты

1. Вырезание фрагмента из середины, а не только обрезка краёв
2. Несколько trim-сегментов с автоматической склейкой
3. Склейка нескольких видео в одно (конкатенация)
4. Полноценный таймлайн с несколькими клипами
5. Поворот видео на 90/180/270 градусов
6. Отражение по горизонтали/вертикали
7. Наложение текста (drawtext): заголовок, подпись, таймкод
8. Водяной знак / логотип поверх видео
9. Fade in / fade out для видео и звука
10. Переходы между клипами (crossfade)
11. Реверс видео
12. Loop: повторить фрагмент N раз
13. Boomerang (вперёд-назад)
14. Цветокоррекция: яркость, контраст, насыщенность (фильтр eq)
15. Фильтры-пресеты: ч/б, сепия, «тёплый», «холодный»
16. Размытие/пикселизация области (замазать лицо, номер машины)
17. Стабилизация тряски (vidstab)
18. Изменение fps (например, 60 -> 30)
19. Zoom/pan эффект (Ken Burns)
20. Crop с пресетами пропорций: 9:16, 1:1, 4:3, 16:9
21. Авто-кадрирование горизонтального видео под вертикальный формат
22. Picture-in-picture: наложение второго видео
23. Хромакей (удаление зелёного фона)
24. Скорость плавная (рамп): разгон/замедление внутри клипа
25. Шаблоны «до/после» (split screen из двух видео)

## Звук

26. Регулировка громкости (не только mute)
27. Нормализация громкости (loudnorm)
28. Fade звука отдельно от видео
29. Замена аудиодорожки: наложить свою музыку
30. Микс: фоновая музыка + оригинальный звук с балансом
31. Извлечение аудио в MP3/WAV
32. Waveform (волновая форма) под слайдером обрезки
33. Удаление шума (afftdn / arnndn)
34. Выбор аудиодорожки, если их несколько
35. Авто-субтитры через whisper.cpp
36. Загрузка SRT и вшивание субтитров в видео (burn-in)

## Превью и UI

37. Двойной range-слайдер для trim одной полосой
38. Интерактивная рамка кадрирования прямо на видео (drag вместо ввода чисел)
39. Полоса миниатюр (filmstrip) вдоль таймлайна
40. Кнопки «начало/конец = текущая позиция плеера»
41. Покадровая навигация (шаг +-1 кадр)
42. Ввод времени вручную в формате 00:01:23.450
43. Горячие клавиши: пробел, I/O для точек входа/выхода
44. Живое превью эффектов: скорость, crop, фильтры через CSS/canvas без рендера
45. Серверное low-res прокси-превью для честного предпросмотра
46. Undo/redo настроек редактирования
47. Сохранение и применение пресетов настроек
48. Прогресс экспорта в процентах (парсить ffmpeg -progress)
49. Прогресс скачивания yt-dlp в процентах
50. Кнопка отмены задачи (kill процесса)
51. Показ метаданных: кодек, битрейт, fps, размер файла
52. Оценка размера результата до экспорта
53. Сравнение «до/после» в ResultPanel
54. История импортов и экспортов в UI
55. Тёмная/светлая тема
56. Локализация (en + ru)
57. Мобильная адаптивность
58. Drag&drop файла прямо в окно
59. Toast-уведомления об ошибках вместо текста в панели
60. Скелетоны/спиннеры на этапах загрузки

71. Выбор кодека (H.265 для меньшего размера)
