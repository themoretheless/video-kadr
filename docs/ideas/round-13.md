# Раунд 13: курированный топ-приоритетов (из ~600 идей)

Это не новые идеи, а **дистилляция** round-11 (100) и round-12 (500) в
приоритизированный список «что строить». Ранжир: ценность для соло/коротко-видео
редактора × вписываемость в текущую архитектуру ÷ трудозатраты, с явной пометкой
зависимостей. Намеренно ~60 пунктов, а не 400: «топ-400 из 600» почти не фильтр.

Обозначения: **S** часы, **M** день-два, **L** неделя+. Зависимости:
`[ffmpeg]` нужна полная сборка ffmpeg (libass/libfreetype/frei0r);
`[ML]` нужна локальная модель (whisper/onnx/...); `[timeline]` нужен мультитрек-таймлайн (Тир 0).

---

## Тир 0 - архитектурный разблокировщик (делать раньше всего «широкого»)

- **Timeline IR + компилятор в один `filter_complex`** (L). Без него мультитрек, оверлеи, диапазонные эффекты, кейфреймы между клипами и переходы между произвольными клипами - не на чём строить. Это Фаза 2 архитектурного плана; половина Тира 3 заблокирована на нём.

## Тир 1 - строить сейчас (высокая отдача, ложится на текущий код, без тяжёлых зависимостей)

Экспорт/кодеки:
1. **Boomerang-экспорт** (S) - `[0]reverse[r];[0][r]concat`; популярно, тривиально.
2. **AV1 (SVT-AV1) и ProRes** (M) - современный и монтажный кодеки; чистое расширение билдера аргументов.
3. **Two-pass под целевой размер/битрейт** (M) - «уместить в N МБ»; частый реальный запрос.
4. **WebP/APNG-экспорт** (M) - лучшая альтернатива gif по весу.
5. **10-bit / lossless вывод** (S) - против бандинга / для промежуточных файлов.
6. **Экспорт кадра в JPG/WebP + копия в буфер** (S) - мелочь, заметная в быту.

Аудио (всё через ffmpeg, без ML):
7. **loudnorm-нормализация при экспорте** (M) - целевой LUFS под платформы; двухпроходно.
8. **Компрессор/лимитер/гейт** (M) - базовая динамика речи; огромный прирост качества звука.
9. **Low/high-pass + telephone-пресет** (S) - дешёвые звуковые эффекты.
10. **Pitch-preserving speed >2x** (S) - цепочка atempo; чинит «бурундука» на ускорении.
11. **Извлечение/замена аудиодорожки, multi-format (wav/flac)** (S) - `-map`/`-c copy`.
12. **Авто-вырезание тишины (silencedetect)** (M) - влог/подкаст-режим; без ML, на встроенном детекторе.

Цвет/эффекты (single-clip, ложатся на текущий vf-конвейер):
13. **LUT-импорт .cube + интенсивность** (M) - один `lut3d`+blend; максимальный визуальный ROI.
14. **Плёночные/look-пресеты** (S-M) - teal-orange, split-toning, faded, day-for-night поверх eq/curves/colorbalance.
15. **Зерно/grain** (M) - дешёвая «киношность».
16. **Unsharp/sharpen + hqdn3d-денойз** (S-M) - резкость и шумодав, частый фикс.
17. **Хромакей (зелёный экран) + despill** (M) - один `chromakey`; высокая ценность, без таймлайна.
18. **Ken Burns / zoompan с кейфреймами** (M) - анимация панорам/зума на одном клипе; уже ложится на `zoompan`.

Геометрия/стабилизация (single-clip):
19. **Стабилизация vidstab (двухпроходная)** (M-L) - самостоятельная, без таймлайна; большой «вау».
20. **Авто-обрезка чёрных полос (cropdetect)** (S) - частый импортный мусор.
21. **lenscorrection / де-фишай + perspective/keystone** (M) - геометрия экшн-камер/документов.
22. **Crop с локом аспекта (16:9/1:1/9:16) + численный ввод** (S) - UX-дыра в текущем кропе.

UX/DevX (чистый фронт или лёгкий бэк):
23. **Режим «до/после» слайдером** (M) - сравнение оригинал/результат.
24. **Скоупы: гистограмма/waveform/vectorscope** (M) - бэкенд рендерит png по кадру; нужно для грейда.
25. **Превью-миниатюры на скраббере** (M) - спрайт кадров; навигация.
26. **Маркеры/главы на таймлайне (клавиша M)** (M) - навигация + экспорт глав.
27. **Лог ffmpeg-команды в панели + «копировать»** (S) - отладка, доверие.
28. **Reveal in Finder/Explorer** (S) - открыть файл в системе.
29. **Восстановление последней сессии** (M) - открытый клип/позиция/стек правок (часть уже есть через проекты).
30. **Дашборд хранилища + очистка кэша/осиротевших** (M) - app.db/cache/proxy растут; нужна гигиена.

## Тир 2 - следующее (высокая отдача, средний труд или лёгкая зависимость)

31. **Авто-субтитры (whisper) с karaoke-стилями** (M) `[ML]` - headline-фича коротких видео; whisper локально.
32. **Наложение текста/титров, lower-thirds, водяной знак** (M) `[ffmpeg]` - drawtext, нужна libfreetype (в Docker-сборке есть).
33. **Импорт/экспорт и стилизация субтитров (.srt/.ass)** (M) `[ffmpeg]` - burn-in через libass или softsub mux.
34. **Фоновая музыка + авто-ducking** (M-L) - второй аудиовход + `sidechaincompress`; частично без полного таймлайна.
35. **Speed ramps (плавное ускорение по сегментам)** (M) - setpts-сегменты + опц. minterpolate.
36. **Переходы между сегментами (xfade-библиотека)** (M) - на текущем concat-пути для соседних кусков (полноценно - Тир 3).
37. **PiP / overlay-клип** (M) - второй вход + `overlay`; частично без таймлайна.
38. **QR-код на видео** (S) - крейт qrcode + overlay.
39. **Запись экрана / вебкамеры** (M-L) - ffmpeg avfoundation/x11grab; новый источник.
40. **Платформенные пресеты соцсетей + safe-zone оверлей** (M) - размеры/битрейт/длительность под TikTok/Shorts/Reels.
41. **Авто-кроп под 9:16 с трекингом субъекта** (L) `[ML]` - реframe для вертикали.
42. **Очередь экспорта с приоритетами** (M) - несколько джоб последовательно (поверх текущей очереди).
43. **Проект в один файл-архив (.veproj) + импорт** (M) - перенос проекта с медиа.
44. **Contact-sheet / превью-спрайт + VTT** (M) - раскадровка и веб-скраббер.
45. **Чаптеры/метаданные в контейнер** (M) - title/теги/главы в mp4/mkv.

### Как этим пользоваться
- Хочешь «вширь и сразу полезное без большой стройки» → бери **Тир 1** сверху вниз.
- Хочешь, чтобы редактор стал «настоящим» → сначала **Тир 0 (Timeline IR)**, он открывает весь Тир 3.
- Хочешь «вау для коротких видео» → **Тир 2 #31 (авто-сабы)** + **#32 титры** + **#34 музыка/ducking**.
- Тир 4 - отдельный трек: требует Python/torch/onnx локально, закладывать инфраструктуру под модели.

Полные формулировки и источники-редакторы - в [round-11.md](round-11.md) и [round-12.md](round-12.md).
