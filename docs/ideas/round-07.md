# Топ-10 идей «как в других редакторах», раунд 7

Раунд 6 реализован (интерактивная рамка кадрирования прямо на видео с углами-ручками
и затемнением вне области; живое CSS-превью цвета/отражения/скорости/громкости).
Здесь следующий конкурентный срез из 10 идей.

1. Вырезание фрагмента из середины (CapCut split + delete) - не только обрезка
   краёв, а удаление куска внутри.
2. Несколько trim-сегментов с автосклейкой (CapCut, Premiere) - набор кусков ->
   один ролик через concat.
3. Склейка нескольких клипов из медиатеки в один (iMovie, CapCut) - порядок
   перетаскиванием.
4. Серверные миниатюры (sprite/первый кадр) для медиатеки и таймлайна (Premiere) -
   endpoint ffmpeg, кэш на диск.
5. Многодорожечный таймлайн с перетаскиванием клипов (CapCut, Premiere).
6. Ручки обрезки прямо на клипе таймлайна (CapCut) - тянешь края клипа.
7. Привязка (snapping) к краям и плейхеду при перетаскивании (Premiere, DaVinci).
8. Плейхед/скраббер с таймкодом над таймлайном (все редакторы).
9. Сетка пропорций/правило третей поверх рамки кадрирования (Photoshop, Premiere).
10. Зум и панорама внутри предпросмотра для точного кадрирования (DaVinci).

Большие списки: round-01..04. round-05..07 - короткие конкурентные срезы под цикл.
