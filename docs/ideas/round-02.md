# Топ-100 идей, раунд 2

Раунд 1 реализован (прогресс/отмена/очередь/таймауты/валидация URL/health/graceful
shutdown на бэкенде; двойной trim-слайдер, горячие клавиши, ввод времени, тосты,
прогресс-бары, метаданные, пресеты пропорций crop на фронте). Здесь следующий топ-100:
оставшиеся актуальные идеи плюс новые, помеченные [новое].
