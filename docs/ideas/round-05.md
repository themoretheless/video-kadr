# Топ-10 идей «как в других редакторах», раунд 5

Раунд 4 реализован (загрузка локального файла через multipart + drag&drop, дизайн
дропзоны и пустого состояния). Реальный e2e прогнан: upload -> probe -> edit ->
H.265/GIF проверены ffprobe. Здесь фокус-список: 10 идей, заимствованных у
известных редакторов, с указанием источника и зачем.

1. Медиатека / бин клипов (Premiere, DaVinci, CapCut) - панель со всеми
   импортированными источниками, перетаскивание в таймлайн, повторное открытие.
2. Многодорожечный таймлайн с перетаскиванием (CapCut, Premiere) - видео/аудио/
   текст дорожки, обрезка ручками на самих клипах.
3. Авто-субтитры и captions «в один клик» (CapCut, Veed) - whisper.cpp -> SRT ->
   стилизованный burn-in с пресетами шрифтов.
4. Текстовые шаблоны и нижние трети (CapCut, Canva) - готовые анимированные
   заголовки, перетащил и поменял текст.
5. Стикеры/эмодзи и оверлеи (CapCut) - PNG/GIF поверх видео с позиционированием.
6. Авто-рефрейм под вертикаль 9:16 с отслеживанием объекта (Premiere Auto Reframe).
7. Библиотека переходов между клипами (CapCut, iMovie) - crossfade, slide, zoom,
   glitch как пресеты.
8. Кривые скорости / speed ramp по ключевым точкам (DaVinci, CapCut) - плавный
   разгон и замедление, freeze-frame.
9. Цветовые пресеты/фильтры с превью на миниатюре (Instagram, CapCut) - сетка
   лук-пресетов, наведение показывает эффект на текущем кадре.
10. Удаление фона / хромакей без зелёнки (CapCut «Remove BG», Premiere) - маска по
    модели или по цвету, замена фона.

Полные большие списки идей: round-01..round-04. Здесь намеренно короткий
конкурентный срез под текущий цикл.
