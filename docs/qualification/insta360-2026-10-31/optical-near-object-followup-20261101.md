## Native implementation

The seam analysis retains the original fine-resolution patch matching, then tries 2x and 4x image levels only for failed fine matches. A coarse proposal must lie outside the fine search range plus its refinement window, pass a fine-resolution NCC refinement, and pass the same fine-resolution forward/back consistency test. It cannot bypass the original competing-peak rejection inside the already-searched range. Search radius is bounded per level; including coarse and fine subpixel refinement, displacement is bounded by four times the configured analysis radius plus six analysis pixels. Sparse visual drift retains its original single-scale behavior.

`Flow::prepare_with_priority` additionally accepts the uncapped optical-axis coverage of each source sample. After measured flow is ready, it samples both actual midpoint-warped views through the same source-row/rolling-shutter hook as final rendering. A binary global cut on the bounded 256x128 body grid chooses lens ownership. Exclusive coverage forces the available lens; its fixed vertices are eliminated exactly and boundary edge costs become overlap-node unary costs; weak axis preference anchors the cut; photometric and gradient disagreement make cutting through an observable foreground boundary expensive. Horizontal graph edges wrap around longitude.

The graph uses an iterative Dinic solver, with no recursion proportional to image size. Its cap is 32,768 image vertices and 40 million arc-work operations, with cancellation checkpoints. If the solver reaches the work budget it supplies no ownership, and output retains the original calibrated blend. A bilinear ownership field provides a narrow crossover. Output only applies it to unresolved residual disagreement: independently supported flow, agreeing colors, partial transparency, missing coverage, zero strength and default feather retain their previous behavior. The RGB-based ownership also gates the source-mask contribution in tracking preparation; agreeing views retain the conservative mask union.

This is a classic image-derived seam cut, not inferred depth or a learned vendor model. Flat, repeated, specular or mutually hidden foregrounds can remain geometrically ambiguous. A cut cannot recover content absent from both views. No multi-frame seam regularizer or general rolling-shutter/occlusion depth solution is claimed.

## Qualification protocol

A standalone harness imports the actual production modules and checks the iterative solver against the exhaustive binary-energy optimum on 32 small graphs. A second observable depth-boundary fixture verifies that the cut routes around the shifted textured foreground: 71 foreground pixels remain, one connected component, compared with the expected single-view width of 68-76 pixels. This rejects the union of both silhouettes and foreground erasure. These standalone checks supplement actual native renderer integration.

The native suite includes large 12x8-pixel displacement with fine radius 4, subpixel bias, occlusion/flat/cancel controls, known-midpoint textured registration, opaque near-object preservation, source-mask/color ownership consistency and bit-identical zero strength. Its actual final results are recorded with the native log and reference measurements after completion.

## Frozen midpoint/coverage correction results

A source-A correspondence cannot be looked up at the virtual midpoint when disparity varies. Rendering now uses a separate midpoint field made from measured correspondences and locally coherent triangles with at least three supported vertices; conflicting/folded surfaces remain unsupported. Gyro correspondences keep their original source-A contract. Target coverage is checked at the actual searched counterpart, allowing valid rim anchors whose unshifted target patch is outside coverage.

The full native integration run passed 14/14 tests, including the real X6 fixture. The nonuniform transition regression admits two trusted samples with average error about 0.064 analysis pixels; an ambiguous 0.70-pixel error remains explicitly low-confidence and is not admitted. Existing subpixel mean errors are below 0.002 pixels for the tested 0.2/0.4/0.7-pixel shifts. Known-midpoint native MSE fell from feather 1854.9045 to 365.2247 (previous flow 404.8337). Actual X6 analysis admitted 60/1067 candidate nodes; patch NCC rose from 0.203638 to 0.878259. The 1024x512 sphere retained 524288 opaque pixels. Measured debug rendering was 5.7511 s feather / 7.2943 s flow.

On the same historical Studio frame and exact prior SO3, default corrected flow scores 30.795418 dB whole sphere, 27.483930 near object and 35.175638 background, versus previous flow 30.789145 / 27.484255 / 35.175213. These near-identical controls show the geometry corrections preserve the accepted baseline; they do not solve the extreme flat close hand. The experimental graph cut defaults to `occlusionStrength=0` because its earlier real result regressed and exposed a hard splice. This is an unresolved quality gap, not full vendor parity.
